# Superficie: UI de contención CBI (`src/api/static/index.html`)

## Modo

Operate. El visitante ejecuta una simulación, cambia parámetros y lee un dictamen. La expresión vive en el detalle; el dato y la acción no se oscurecen.

## Audiencia y trabajo

Jurado y equipos de Spookython 2026 Track B. Abren `python run.py`, ajustan el escenario, lanzan Monte Carlo, revisan KPIs, territorio, prioridad de vacunación y memo ejecutivo, y prueban brotes sorpresa.

## Dirección elegida

Expediente de contención CBI: un caso oficial desclasificado abierto sobre una mesa de acero del COE, con hojas de papel, manifiestos mecanografiados y sellos de goma. Se conservan estructura, IDs, funciones, pestañas y textos existentes.

## Alcance

Solo `src/api/static/index.html`. No se toca el motor, los endpoints, la SPA React ni los tests.

## Decisión pendiente

Ninguna. Paleta delegada por el usuario.
